## Our Organic Formula

ClearView Green's proprietary cleaning solution uses only:

- Distilled water
- White distilled vinegar (5% acetic acid)
- Unscented castile soap (plant-derived)
- Isopropyl alcohol 70% (pharmaceutical grade)

**Cost per gallon: ~$0.37. Zero toxic runoff. Biodegrades within 24 hours.**

As an EH&S-managed business, we maintain current SDS documentation for all formula ingredients and make them available to customers, employees, or emergency responders upon request. See the [SDS Index](docs/business-docs/SDS-Index.md).
